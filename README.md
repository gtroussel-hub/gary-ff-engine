# gary-ff-engine
Gary FF Engine is a personal fantasy football analytics and draft preparation project.

The application is intended to use read-only Fantasy Sports data for leagues associated with the owner's account. Data may include league settings, scoring rules, teams, rosters, players, standings, matchups, and draft-related information.

Fantasy data will be combined with public NFL statistical data to support player evaluation, roster construction, and draft decisions.

This project is for personal use only. It is not a commercial service, and Yahoo Fantasy data will not be sold or redistributed.
